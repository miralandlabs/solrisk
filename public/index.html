solrisk

Solana wallet risk scoring. One call, one answer, x402 micropayment.

GET /api/v1/wallet-risk?wallet=<base58>

Returns a 0–100 risk score, band (LOW / MEDIUM / HIGH / CRITICAL), chain-derived signals, and label matches. $0.05 USDC per call via x402 v2.

Signals

Age, activity cadence, counterparty diversity (approx.), dust-farming patterns, funding-source risk (planned), OFAC sanctions (limited), mixer/drainer interaction (direct only), verified-entity labels (limited).

For agents

Stable JSON schema with scoring_version, confidence, and machine-readable flags[]. No signup, no API key — just PAYMENT-SIGNATURE.
